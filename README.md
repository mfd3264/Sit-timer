# SIT Timer

A custom workout timer for Sprint Interval Training (SIT): short all-out sprints alternating with strength work, repeated for a set number of cycles.

## Workout structure

1. Prepare: a countdown before the first sprint
2. Sprint: 30 seconds, all out, on the bike
3. Transition: a few seconds to clip out and move to the weights
4. Weights: 4 minutes of strength work
5. Transition: a few seconds to get back on the bike and clip in

Steps 2 through 5 repeat for the number of cycles you set (typically 6). All durations and the cycle count are adjustable.

## Features

- Pause and resume without losing your place
- Skip forward to the next phase, for example to end a weights set early and go straight to the next sprint
- Audio beeps at phase changes and a countdown in the final seconds, so you don't need to watch the screen
- Progress ring and cycle counter (for example, CYCLE 3 / 6)
- Keeps the screen awake during a workout

## Install on iPhone

1. Open https://mfd3264.github.io/Sit-timer/ in Safari
2. Tap the Share button
3. Tap Add to Home Screen, then Add

It opens full screen like a regular app. No App Store download or account is needed.
